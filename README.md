# Little Planet — Shooter Prototype

Процедурный шутер на сфере-планете: каждая игра — уникальная планета со своим
климатом, небом, флорой и врагами. Всё генерируется из одного зерна-сид: вырубите
джунгли дробовиком на закате красного карлика, разберитесь с бандой космических
астронавтов и выберетесь отсюда живым.

Three.js (локальный npm-пакет, без CDN), Vanilla JS ES-модулями, все звуки
синтезируются в реальном времени через Web Audio — никаких загружаемых файлов.

## Игровой процесс

- **Выживи и победи.** Вас окружают 4–7 враждебных астронавтов: они подбирают
  оружие, охотятся друг за другом и за вами, уклоняются от выстрелов и не стоят
  на месте. Справитесь со всеми — эвакуируйтесь.
- **У вас есть жизни.** Получите слишком много урона — поражение. Нажмите Y,
  чтобы начать новую игру (очки при этом обнулятся).
- **Охота за оружием.** Планета усеяна стволами: пистолеты, дробовики, снайперки,
  пулемёты и энергетическое оружие — лазер, плазма, гаусс. Подбирайте лучшее,
  меняйте по ходу боя.
- **Тайна разбитого корабля.** Где-то на планете лежит потерпевший крушение
  корабль. Исследуйте его первым, пока это не сделали враги — и получите очко.
- **Живой мир.** Леса, джунгли, пустыни, кристальные и грибные рощи; кусты и
  деревья ломаются от выстрелов. Над головой — звёзды, планеты с кольцами,
  чёрные дыры и галактики.
- **Журнал событий** слева не даст пропустить ничего важного: кто кого убил,
  кто что подобрал, кто добрался до корабля.

## Управление

- WASD — движение
- Пробел — прыжок
- Мышь — осмотреться
- ЛКМ — стрельба (удержание — автоогонь)
- R — перезарядка
- E — подобрать оружие / исследовать корабль
- Y — эвакуация после победы / новая игра после поражения
- Esc — пауза

## Запуск

Требуется Python 3 и установленные зависимости:

```
npm install
python serve.py          # dev-сервер без кэша, порт 7000 (рекомендуется)
# или: python -m http.server 7000
```

Откройте **http://localhost:7000**

## Структура проекта

```
littleplanet/
  index.html            — HTML + importmap + CSS-интерфейс
  js/
    main.js             — сцена, игровой цикл, коллизии, журнал
    planet.js           — планета: рельеф, кратеры, цвет по высоте
    player.js           — управление героем на сфере
    sky.js              — небо: звёзды, чёрные дыры, планеты, кольца
    vegetation.js       — флора: деревья, пальмы, кактусы, кристаллы, грибы
    weapons.js          — арсенал: типы, боеприпасы, снаряды
    enemy.js            — ИИ врагов: охота за оружием, бой, уклонение
    noise.js            — 3D Perlin-шум по сиду
    sound.js            — процедурный звук с позиционированием
    ship.js             — разбитый корабль: генерация и исследование
    namegen.js          — имена планет и врагов
  serve.py              — dev-сервер
```
